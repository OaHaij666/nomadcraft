# 用户托管意愿（2026-10-10）

已增加个人设置页 /preferences，普通用户与管理员均可进入；账号弹窗也提供同一控件。四档为高、中、低、无，默认中。账号字段为 hostingWillingness，取值 high/medium/low/none，未来选主机算法在服务端读取这个字段。

GET /api/auth/hosting-preference 读取当前会话账号，PUT 同一路径只接受 {hostingWillingness: value}。禁止目标 UUID、权限字段和多余字段；不改变用户角色、实例 ACL 或游戏 OP。已有账号记录没有该字段时，由 User 的默认属性补为 medium；修改使用既有 Storage 适配器保存，重启后仍保留。

高/中/低表示未来候选排序倾向，无表示不参与自动选主机。当前自动选主机尚未启用，意愿设置不强制终止现有托管任务，也不替代管理员签发的托管授权。默认中不意味着此轮会自动启动本机 Java 服务端。

前端失败状态保留当前选择以便重试；初次读取失败时禁止提交，避免把未读取到的服务器偏好当作默认成功。新页面使用现有深色主题变量，复用同一组件到账号弹窗。

验证包括：普通用户保存四档、默认与旧账号兼容、重启持久化、账号隔离、拒绝伪造 UUID/权限/枚举值；前端四选项、保存后重新读取、保存失败重试与读取失败处理。后端 87 项测试、前端 70 项测试及类型检查通过；common 9 项、daemon 144 项测试通过。完整 HTTP 联调九组通过，Windows 下 Docker 跳过；前后端构建与定向 lint 通过。真实普通用户浏览器验证保存返回 200、刷新后仍为 none，390px 手机布局没有横向溢出，记录见 docs/proofs/hosting-preference-2026-10-10.json。界面和 API 预览已恢复。
